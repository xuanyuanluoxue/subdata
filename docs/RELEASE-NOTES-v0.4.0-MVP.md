# v0.4.0-MVP 发布说明

## 这是什么

 的 MVP 公开版：一个 Xposed/LSPosed 模块，让任意 App 在同一台设备上拥有多套互相隔离的数据目录（slot），用于同一 App 的多账号/多环境切换。

- 版本：0.4.0-MVP（versionCode 8）
- APK：（debug key 签名，便于直接安装试用；不适合上架分发）
- 依赖：Android 8.1+、LSPosed 或 Vector 2.x 框架、目标 App 需在模块作用域内

## 功能范围（MVP）

- 数据目录按 slot 隔离（CE / DE / EXT 三棵树）
- 槽管理：创建 / 切换 / 删除 / 体积统计 / 配置体检
- 外部存储克隆（换槽不再丢外置资源）
- 半成品槽自愈 + 原子写
- 小米超级岛「副本数据」提示（非主槽时）
- 内嵌 MCP 服务（默认 127.0.0.1:8773、Bearer token、11 个工具），可被 AI 客户端调用

## 明确不在开源版本内的能力

- **任何设备身份 / 设备指纹的修改或伪造功能**（例如按槽生成不同 device_id）——这类实验特性不属于开源发布范围，已从公开代码中移除，仅在维护者本地分支保留。

## 安全与合规

- 本项目只做「同一设备上多个数据目录」的通用隔离，**不修改目标 App 的账号体系、不伪造设备指纹、不绕过服务端风控**。
- 请遵守目标 App 的服务条款；因使用本模块导致的账号风险由使用者自行承担。
- 模块只在被勾选的 App 进程内运行，不修改系统分区、不 hook system_server。

## 已知限制

- 首次给某槽克隆数据时首启会变慢（数据量大时更明显）
- 部分 App 若把路径写死在 native 层（.so 直接 open），hook 无法覆盖
- 超级岛提示依赖 HyperOS 焦点通知，其他 ROM 上只会是普通常驻通知
